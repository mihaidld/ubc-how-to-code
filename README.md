# Courses How to Code Simple Data and Complex Data

#### Description:

Work during following programming courses from University of British Columbia on Edx in audit mode:

- [How to Code Simple Data](https://www.edx.org/learn/coding/university-of-british-columbia-how-to-code-simple-data) focuses on learning a systematic programming method rather than a programming language in order to program well in any language.
- [How to Code Complex Data](https://www.edx.org/learn/coding/university-of-british-columbia-how-to-code-complex-data) teaches how to design more complex programs, using new data structures, abstraction, and generative recursion.

#### Techniques:

- Develop program requirements
- Produce programs with consistent structure that are easy to modify later
- Make programs more reliable by building tests as an integral part of the programming process.

#### Learnings:

- How to represent information as data
- How to focus each part of the program on a single task
- How to use examples and tests to clarify what the program should do
- How to simplify the structure of the program using common patterns
- Recognize and represent more complicated information
- How to identify commonalities in data definitions and functions
- How to avoid repetition using abstraction
- How to design functions that operate on graphs
- How to design programs that search a given problem space to find a valid solution
